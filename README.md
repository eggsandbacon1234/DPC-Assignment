# TEB3033 Distributed Photo Sharing System
Distributed Photo Sharing and Commenting System built using React, Node.js, AWS EC2, AWS S3, and AWS RDS for TEB3033 Distributed and Parallel Computing Project.

## Technologies

- React.js
- Node.js
- Express.js
- AWS EC2
- AWS S3
- AWS RDS (MySQL)
- GitHub

## Features

- User Registration
- User Login
- Photo Upload
- Photo Sharing
- Commenting System
- Multi-User Support
- Search & Filter (Bonus)

## Architecture

Users
→ React Frontend
→ Node.js Backend
→ AWS RDS
→ AWS S3

## Deployment

- EC2
- S3
- RDS
